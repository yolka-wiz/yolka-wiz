## 🌟 What I'm building

### [albdf](https://github.com/yolka-wiz/al-bdf-engine) — RTL-first PDF engine for Linux

A headless PDF editing **library + CLI** built for **Arabic, Persian & Hebrew**.
Fork of PDF4QT with a differentiator that matters: **correct RTL text write and
search** — lam-alef ligatures, tashkeel normalization, cross-line phrase
matching — the things most PDF tools get wrong or skip entirely.

> Status: **v0.2.0 released** · deterministic builds · CI green · optional GUI
> (the PDF4QT apps now build against our modified core)
